The first release of `ghx`, a CLI that coding agents such as Claude Code call instead of the GitHub CLI. It wraps `gh`, which still handles auth and HTTP. Writes go through strict validation against the repo's `.github/ghx.json`, and each common question is one plain call that returns JSON, so agents don't need pipes, `--jq`, `sleep` or `timeout`.

## Install

On macOS or Linux (x64 or arm64), with `gh` 2.81.0 or later logged in:

```sh
curl -fsSL https://github.com/thegoldenmule/gh-for-agents/releases/latest/download/install.sh | sh
ghx install   # adds the Claude Code hook and the CLAUDE.md snippet
```

The script installs a standalone binary into `~/.local/bin`, checked against `SHA256SUMS`; no Node.js needed. On Windows, or to use your own Node.js 24+, install the npm package from this release instead: `npm i -g https://github.com/thegoldenmule/gh-for-agents/releases/latest/download/ghx.tgz`. Every asset carries a build provenance attestation (`gh attestation verify <asset> --repo thegoldenmule/gh-for-agents`).

## What's in it

- **PRs:** `pr create` and `pr edit` from validated JSON, `pr status` (state, mergeability, CI for the head SHA and feedback in one call), `pr feedback`, `pr comment`, `pr review`, `pr resolve`, `pr ready`, and `pr merge` / `pr land` pinned to the head SHA under the repo's merge policy.
- **CI:** `ci why` diagnoses a failing run in one call; `ci wait` waits for CI and prints one JSON summary with an exit code per outcome; `ci rerun` and `ci retrigger`.
- **Setup:** `init` writes a starter `.github/ghx.json`; `doctor` checks gh, auth, git and the config; `install` / `uninstall` manage the Claude Code PreToolUse hook, which steers raw `gh` writes and reads to `ghx` in configured repos and places CI waits in the background.
- **Output control:** `--fields` and `--brief` on every JSON command; `gh`-shaped reads typed through `ghx` run their `ghx` equivalent.

See the [README](https://github.com/thegoldenmule/gh-for-agents#readme) and [docs/agents](https://github.com/thegoldenmule/gh-for-agents/tree/main/docs/agents) for the full command reference.

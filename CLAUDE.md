# gh-for-agents

## Git

- Always push finished work to `origin/main` without asking. This overrides the
  global "never push" rule for this repo only.
- Work on `main` in small logical commits; push once `pnpm check` passes.
- Still ask before history-rewriting commands (force-push, reset, rebase) and
  before tagging or publishing a release ([RELEASING.md](RELEASING.md)).
